# Newsreader SemiBold (display font)

The site's display serif (`--font-display` in `src/styles/global.css`).

- Newsreader by Production Type, licensed under the SIL Open Font License 1.1
  (https://openfontlicense.org). Source: Google Fonts.
- `Newsreader-SemiBold-latin.woff2`: weight 600, optical size 72 (the
  display cut), Latin subset (U+0000-00FF plus common punctuation), 23 KB.
